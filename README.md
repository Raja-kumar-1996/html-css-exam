# 🧠 HTML & CSS Online Exam

This repository contains a **secure online HTML & CSS coding exam platform**, designed for conducting web development assessments safely and efficiently.  
It helps prevent cheating by disabling copy/paste, right-click, and tab switching when used with **Safe Exam Browser**.

---

## 🚀 Features

- 💻 Simple HTML & CSS coding interface  
- ⏱️ Timer option for fixed exam duration  
- 📝 Code editor or textarea for writing answers  
- 🚫 Copy, Cut, and Paste disabled  
- 🚫 Right Click disabled  
- 🔒 Works with **Safe Exam Browser (SEB)** to prevent:
  - Switching to other windows or tabs  
  - Opening other websites  
  - Taking screenshots  

---

## 🧩 How It Works

1. The **examiner (teacher)** hosts this exam on GitHub Pages.  
2. The **student** opens the exam using **Safe Exam Browser (SEB)**.  
3. The student writes HTML/CSS code directly on the page.  
4. The student clicks **Submit** to send answers to a Google Form or backend server.
